Privacy Policy

My Slide Image Downloader · Effective date: October 1, 2026

English 한국어

This policy applies to the My Slide Image Downloader Chrome extension (version 0.1.7 and later) and its companion file-selection page at https://unnormaljh.github.io/picker.html.

1. Summary

My Slide Image Downloader lets you download images from Google Slides presentations, either one at a time from the right-click menu or in bulk as a ZIP file. All image extraction, format conversion, and ZIP compression happen locally in your browser. The developer does not operate any server that receives your data, and does not collect, sell, or share your personal information or presentation content.

2. Information the extension accesses

a) Google account authorization

To read the presentation you are viewing, the extension asks you to sign in with Google through Chrome's built-in identity feature. It requests only this permission:

  • https://www.googleapis.com/auth/drive.file: access to the specific Google Drive files that you select or open with this extension. It does not grant access to the rest of your Google Drive.

Chrome issues an OAuth access token, and Chrome manages that token. The extension uses it only to call Google APIs directly from your browser. The token is never sent to the developer or to any third party.

b) Presentation content

When you open the extension on a Google Slides presentation, it requests that presentation's structure (slide list, title, and image URLs) from the Google Slides API (slides.googleapis.com). Image files are then downloaded directly from Google's servers to your computer.

c) Current page address

The extension can access only these Google hosts: docs.google.com, *.googleusercontent.com, and slides.googleapis.com. It uses the address of your active tab only to detect whether it is a Google Slides presentation and to get the presentation ID. It cannot see the addresses of other websites and does not record or transmit your browsing history.

d) Images you right-click

When you choose "Image download" from the right-click menu inside Google Slides, the extension fetches that single image and saves it to your Downloads folder.

3. File selection page (Google Picker)

Google's security policy may require you to confirm access to a presentation before the extension can read it. In that case, the extension opens a small window showing https://unnormaljh.github.io/picker.html, which runs Google's official file picker (Google Picker API).

  • The page receives your access token from the extension through Chrome's extension messaging. The token is not placed in the page address and is not stored by the page.
  • The page passes the token only to Google's Picker service so that Google can show your files.
  • After you select a file, the page sends only the selected file ID back to the extension. It never receives or handles your presentation content.
  • The page is hosted on GitHub Pages. Like any website, GitHub may log standard request information (such as your IP address and browser type). See the GitHub General Privacy Statement.
  • The page loads Google's Picker script from apis.google.com. The Google Privacy Policy applies to that interaction.

4. Data stored on your device

  • Presentation data cache (chrome.storage.local): the presentation structure returned by the Google Slides API (slide list, title, image URLs), keyed by presentation ID, so the extension can reopen quickly. The cache is considered expired after 25 minutes and is then fetched again. You can clear it and reload the presentation at any time with the "Reset" button in the extension. All cached data is deleted when you remove the extension.
  • Temporary file-selection state (chrome.storage.session): the presentation ID and window ID of an in-progress file selection. Chrome clears this automatically when you close the browser.

This data stays in your browser and is never transmitted to the developer.

5. Third-party services

The extension communicates only with these services, and only to provide its features:

  • Google: Sign-in, Google Slides API, Google Picker, Google image servers, and Google Fonts for the extension's interface font (Google Privacy Policy).
  • GitHub Pages: hosting of the file selection page.

No analytics, advertising, or tracking services are used.

6. Google API Services — Limited Use disclosure

My Slide Image Downloader's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Specifically:

  • Google user data is used only to provide the image download features that you can see in the extension's interface.
  • Google user data is not transferred to anyone, except as needed to provide those features, to comply with applicable law, or as part of a merger, acquisition, or sale of assets with notice to users.
  • Google user data is not used for advertising, including personalized or retargeted ads.
  • No human reads Google user data, except with your explicit consent, for security purposes, to comply with applicable law, or when the data is aggregated and anonymized for internal operations.
  • Google user data is not used to train artificial intelligence or machine learning models.

7. Revoking access

You can revoke the extension's access to your Google account at any time at https://myaccount.google.com/permissions. Removing the extension deletes all data it stored locally.

8. Children's privacy

The extension is not directed at children under 13 and does not knowingly collect information from children.

9. Changes to this policy

If this policy changes, we will post the updated version on this page and update the effective date above.

10. Contact

My Slide Image Downloader · 시행일: 2026년 10월 1일

본 방침은 My Slide Image Downloader 크롬 확장 프로그램(0.1.7 이상)과 함께 사용되는 파일 선택 페이지 https://unnormaljh.github.io/picker.html에 적용됩니다.

1. 요약

My Slide Image Downloader는 구글 슬라이드 프레젠테이션의 이미지를 우클릭 메뉴로 한 장씩, 또는 ZIP 파일로 한 번에 내려받을 수 있게 해 줍니다. 이미지 추출, 포맷 변환, ZIP 압축은 모두 사용자의 브라우저 안에서 처리됩니다. 개발자는 사용자 데이터를 받는 서버를 운영하지 않으며, 개인정보나 프레젠테이션 내용을 수집·판매·공유하지 않습니다.

2. 확장 프로그램이 접근하는 정보

가) Google 계정 인증

현재 보고 있는 프레젠테이션을 읽기 위해, 크롬에 내장된 계정 인증 기능으로 Google 로그인을 요청합니다. 요청하는 권한은 다음 하나뿐입니다.

  • https://www.googleapis.com/auth/drive.file: 사용자가 이 확장 프로그램에서 직접 선택하거나 연 파일에만 접근할 수 있는 권한입니다. 사용자의 Google 드라이브 전체에 접근하는 권한이 아닙니다.

OAuth 액세스 토큰은 크롬이 발급하고 관리합니다. 확장 프로그램은 이 토큰을 브라우저에서 Google API를 직접 호출하는 데에만 사용하며, 개발자나 제3자에게 보내지 않습니다.

나) 프레젠테이션 내용

구글 슬라이드에서 확장 프로그램을 열면, Google Slides API(slides.googleapis.com)에서 해당 프레젠테이션의 구조(슬라이드 목록, 제목, 이미지 주소)를 받아 옵니다. 이미지 파일은 Google 서버에서 사용자의 컴퓨터로 바로 내려받습니다.

다) 현재 페이지 주소

확장 프로그램이 접근할 수 있는 곳은 Google 호스트인 docs.google.com, *.googleusercontent.com, slides.googleapis.com뿐입니다. 활성 탭의 주소는 구글 슬라이드인지 확인하고 프레젠테이션 ID를 알아내는 용도로만 사용합니다. 다른 웹사이트의 주소는 볼 수 없으며, 방문 기록을 저장하거나 전송하지 않습니다.

라) 우클릭한 이미지

구글 슬라이드 안에서 우클릭 메뉴의 "이미지 다운로드"를 누르면, 그 이미지 한 장을 가져와 다운로드 폴더에 저장합니다.

3. 파일 선택 페이지 (Google Picker)

Google 보안 정책에 따라, 확장 프로그램이 프레젠테이션을 읽기 전에 사용자가 파일 접근을 확인해야 할 수 있습니다. 이 경우 확장 프로그램은 https://unnormaljh.github.io/picker.html을 작은 창으로 열어 Google 공식 파일 선택기(Google Picker API)를 띄웁니다.

  • 이 페이지는 크롬 확장 메시지 기능으로 확장 프로그램에서 액세스 토큰을 전달받습니다. 토큰은 페이지 주소에 포함되지 않으며, 페이지에 저장되지도 않습니다.
  • 페이지는 Google이 사용자의 파일 목록을 보여 줄 수 있도록, 토큰을 Google Picker 서비스에만 전달합니다.
  • 파일을 선택하면 선택한 파일 ID만 확장 프로그램으로 돌려보냅니다. 프레젠테이션 내용은 받거나 처리하지 않습니다.
  • 이 페이지는 GitHub Pages에서 호스팅됩니다. 일반 웹사이트와 마찬가지로 GitHub가 IP 주소, 브라우저 종류 등 기본 접속 정보를 기록할 수 있습니다. GitHub 개인정보처리방침을 참고하세요.
  • 페이지는 apis.google.com에서 Google Picker 스크립트를 불러옵니다. 이 과정에는 Google 개인정보처리방침이 적용됩니다.

4. 기기에 저장되는 데이터

  • 프레젠테이션 데이터 캐시 (chrome.storage.local): 빠르게 다시 열 수 있도록 Google Slides API가 돌려준 프레젠테이션 구조(슬라이드 목록, 제목, 이미지 주소)를 프레젠테이션 ID별로 저장합니다. 25분이 지나면 만료된 것으로 보고 다시 받아 옵니다. 확장 프로그램의 "초기화" 버튼을 누르면 언제든 캐시를 지우고 다시 불러올 수 있으며, 확장 프로그램을 삭제하면 모두 지워집니다.
  • 파일 선택 진행 상태 (chrome.storage.session): 진행 중인 파일 선택의 프레젠테이션 ID와 창 ID입니다. 브라우저를 닫으면 크롬이 자동으로 지웁니다.

이 데이터는 사용자의 브라우저에만 남으며, 개발자에게 전송되지 않습니다.
